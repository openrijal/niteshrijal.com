SuperGrok Heavy is $300 a month. That includes top-tier Grok, X Premium+, and the highest Grok Bot usage if you link the account to Cursor.

The free Cursor Ultra promo ended late August. Linking now only grants Bot quota. It does not give you the Ultra plan. Ultra is separate, at $200. [Cursor pricing](https://cursor.com/pricing).

Easy to read this as Cursor Ultra included. It isn't.

## What the $300 covers

X Premium+ is included. [Pricing](https://help.x.com/en/using-x/x-premium). Top-tier Grok is the chat side. [Plans](https://x.ai/pricing). The Bot piece is usage, and the high quota only shows up when that Grok account is linked to Cursor. The coding plan is not in the $300.

## Google is the next closest

Gemini Ultra plus Antigravity is the nearest bundle I can point at. [Gemini plans](https://gemini.google/subscriptions/). [Antigravity plans](https://antigravity.google/pricing). You get a strong chat model and an IDE.

Honestly, it is not that great for serious coding yet. You also don't get a Bot. Spark exists, and it ain't as good.

So you cover chat and a coding environment. You don't cover the agent-that-does-work job. For heavy Grok and Bot work, Heavy is the better fit, and the coding side still feels behind Cursor plus Claude Code when the task is real.

## OpenAI covers more surfaces, still split

With OpenAI you get Codex for coding, and a desktop app that is pretty good. [ChatGPT plans](https://openai.com/chatgpt/pricing). You can point that subscription at something like Hermes or OpenClaw if you want a personal assistant, computer use included if it actually works that day. ChatGPT on web and mobile covers general chat.

That's a real stack. Coding, assistant, chat. The catch is you are assembling it. The subscription is the token budget. The assistant is a separate product you wire up. It works. It is not one product.

## Anthropic is the best at one job

Claude's desktop and mobile apps, plus Claude Code in the terminal. [Plans](https://claude.com/pricing). I can't beat this for coding or for raw intelligence.

That's also all you get. No X Premium+. No Grok Bot quota. If coding is the only job, stop here.

## Perplexity

Perplexity is a solid chat and research tool, plus computer use. [Plans](https://www.perplexity.ai/hub/pricing). Good at looking things up and then doing something with the browser. It is not a coding IDE, and it is not trying to be X.

Useful. Different job.

## What I actually want from a stack

I don't need five logins that each do most of one thing.

I want:

- A place to write and ship code. Cursor, or Claude Code when the task is gnarly.
- A model I trust for the hard reasoning. Claude still wins that for me.
- A chat surface I already open. Grok.
- An agent that can do work, not just talk. That's the Bot, and Heavy is where the high quota lives.
- A social account, which is X, because Premium+ comes with Heavy.

Google gets you close on paper. OpenAI gets you close if you are willing to wire Hermes or OpenClaw yourself. Anthropic wins the coding comparison and loses the "what else do I get" comparison. Perplexity wins research plus computer use, and doesn't pretend to be the editor.
